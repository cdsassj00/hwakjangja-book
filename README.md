# 확장자의 재발견

낯선 파일 확장자들을 하나씩 열어 그 정체를 밝히고, 그 구조로 **무엇을 자동화할 수 있는지**, 그 일을 **AI에게 어떻게 시키는지**까지 안내하는 비개발자용 실용 교양서입니다. (자매편: *브라우저의 재발견*)

## 위키독스 연동 (자동 발행)

이 저장소는 [github-wikidocs](https://github.com/pahkey/github-wikidocs) 규칙을 따릅니다. **`main` 브랜치에 push하면 위키독스 책에 자동 반영**됩니다.

```
├── TOC.md          # 목차 (위키독스 페이지 계층 정의)
├── pages/          # 각 장 마크다운 (번호 접두사 + kebab-case)
└── assets/         # 이미지 (페이지에서 ../assets/ 로 참조)
```

### 처음 한 번: 위키독스에 연결
1. 이 폴더를 GitHub 새 저장소로 push 한다.
2. 위키독스 → **새 책 만들기 → 깃허브 연동** → 이 저장소 URL을 연결한다.
3. 이후 push마다 자동 동기화된다.

### 새 장 추가 (반복 작업)
1. `pages/NN-slug.md` 생성 (H1 제목은 `# NN. 제목`).
2. `TOC.md`에 한 줄 추가.
3. 그림은 `assets/`에 넣고 `../assets/파일.png` 로 참조.
4. `git add . && git commit -m "docs: add ch NN" && git push`.

작성 규칙은 `AGENTS.md`에 정리되어 있어, AI 코딩 도구에게 "이 규칙대로 다음 장을 써 줘"라고 시키면 그대로 따릅니다.
