# 『생성형AI시대, 확장자의 재발견』 SNS 홍보 문구

원칙 세 가지.
1. **책에서 직접 측정한 숫자만 쓴다.** 지어낸 통계나 과장 없이. 모든 문구의 근거가 본문에 있다.
2. **훅은 사고 장면으로.** "이런 걸 배웁니다"가 아니라 "이런 일이 지금 벌어지고 있습니다".
3. **겁주고 끝내지 않는다.** 마지막에 해법이나 다음 행동이 있어야 한다.

## 스레드 (Threads) — 낱개 포스트

### 1. 가장 강한 훅 · PDF 마스킹
```
PDF에서 개인정보를 검은 사각형으로 가려 보낸 적 있으신가요.

그 검은 칠은 글자를 지운 게 아니라
글자 위에 도형을 얹은 겁니다.

글자는 그 아래 그대로 살아 있어서
드래그해서 복사하면 가려 놓은 이름과 주민번호가
그대로 나옵니다.

공공기관과 대기업에서 실제로 여러 번 사고가 났습니다.
```

### 2. 엑셀이 몰래 바꾸는 값
```
급여 시스템에서 직원 300명 명단을 CSV로 뽑았습니다.
제대로 나왔는지 엑셀로 열어서 확인하고 저장했습니다.

그리고 새 시스템에 올렸더니 절반이 매칭 실패.

원인은 사번이었습니다.
00123 이던 사람들이 123 으로 바뀌어 있었습니다.

엑셀이 앞자리 0을 지운 겁니다.
확인한 것이 죄가 된 셈입니다.
```

### 3. 카드번호 손상 — 가장 무서운 것
```
CSV에 적힌 16자리 카드번호를 엑셀로 열면
1234567890123456 이 1234567890123450 이 됩니다.

마지막 6이 0으로 바뀝니다.
엑셀은 15자리까지만 정확히 기억하고 뒤는 버립니다.

화면으로는 알아채기 어렵고,
그 상태로 저장하면 원본까지 망가집니다.

14자리까지는 멀쩡했습니다.
```

### 4. 한글 파일의 정체
```
한글 프로그램이 없는 컴퓨터에서
.hwpx 파일이 안 열릴 때.

파일 이름 끝을 .zip 으로 바꿔 보세요.
열립니다.

한글 문서는 사실 압축파일입니다.
그리고 이건 워드, 엑셀, 파워포인트, 전자책도
전부 마찬가지입니다.
```

### 5. 압축의 진실
```
사진 500장을 압축해서 메일로 보내려다
용량이 그대로여서 당황한 적 있으신가요.

직접 재봤습니다.

텍스트 파일: 16,000바이트 → 217바이트 (1.4%)
사진(JPG): 292,673바이트 → 290,475바이트 (99.2%)

사진은 이미 압축된 상태라 더 짜낼 게 없습니다.
사진 용량은 압축이 아니라 다른 방법으로 줄여야 합니다.
```

### 6. 회의 녹음
```
한 시간짜리 회의 녹음이 600MB라 메일이 안 갑니다.

WAV로 저장됐기 때문입니다.
MP3로 바꾸면 같은 한 시간이 55MB가 됩니다.
열 배 넘게 줄어드는데 귀로는 차이를 느끼기 어렵습니다.

그리고 파일이 가벼워지면
AI에게 넘겨 회의록을 만들게 할 수 있습니다.

받아 적느라 회의에 못 끼던 일이 사라집니다.
```

### 7. 아이폰 사진
```
"확장자만 .jpg 로 바꾸면 되지 않나요?"

안 됩니다.

HEIC 파일을 복사해 이름만 .jpg 로 바꾼 뒤
프로그램에 열게 해봤더니 이렇게 답했습니다.
"이 파일의 실제 형식은 HEIF입니다."

이름은 바뀌었지만 내용은 그대로입니다.
변환은 이름을 바꾸는 게 아니라 내용을 다시 만드는 일입니다.
```

### 8. 세금계산서
```
거래처가 세금계산서를 .xml 파일로 보내왔습니다.
안 열려서 다시 보내 달라고 했습니다.

그런데 그게 정본입니다.

우리나라 전자세금계산서는
법으로 XML 파일 자체를 주고받게 되어 있습니다.

흔히 보는 PDF는 사람이 읽으라고 만든 사본이고,
세무 자료로서 효력을 갖는 원본은 그 낯선 파일 쪽입니다.
```

### 9. 설정 파일
```
사내 챗봇의 업무시간을 바꾸려고
개발업체에 메일을 씁니다. 답은 사흘 뒤에 옵니다.

그런데 업체가 고치는 건
config.yaml 파일의 한 줄입니다.

그 파일은 회사 서버에 있고, 열면 한글이 그대로 적혀 있습니다.

"챗봇이 이상해요" 대신
"15번째 줄 내선번호에 따옴표가 빠진 것 같습니다"라고
말할 수 있게 되는 것. 그게 이 책의 목표입니다.
```
